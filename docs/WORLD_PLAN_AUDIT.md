## 首屏和数据规模

浏览器不再启动逐社区请求和轮询任务，只读取一个预建世界状态。服务端目录更新与历史补齐独立运行，慢来源不会阻止已有世界出现。历史事件与当前居民投影分别存储；首屏最多读取 10,000 条居民状态，加每社区交易与发言各最近八条，不下载全部事件库。

当前落地是单写进程、持久 SQLite WAL、SSE 的可运行版本。尚未做生产大规模容量验证；不能据此承诺无限事件吞吐或固定毫秒 SLA。更大规模可以保持同样的快照/序列协议，把底层迁移到分区事件库和消息流，详见后端 WORLD_RUNTIME.md。

## 实时小镇交互复核

- NodeReal `newHeads` 直接触发已确认协议日志投影；同一时刻只运行一个实时投影，繁忙期间的新区块合并为一次追赶最新链头。1.5 秒 HTTP 调度兜底，不用点击播放。
- 正常实时扫描只读新增已确认区块；锚点变化时回查重组窗口，避免每轮重复扫描整个窗口。选中居民发生买卖、转账或 IPShare 动作时，资产面板自动请求新的固定区块快照。
- 链上动作、历史回填、X 内容分别保留来源。新事件驱动步行动画、场所灯光与行动气泡；有上一场所记录时沿街道转场，时间戳过旧的回填不冒充现在发生。
- 恢复被误写的世界 CSS，并新增样式格式回归校验。居民资产、IPShare 双向关系及 X 原文面板已补齐视觉样式，支持减少动态效果的系统设置。
- 这是数据驱动的世界观察与跟随；不会因展示“游戏感”而自动替用户交易。钱包操作与协作任务仍属于后续功能。
