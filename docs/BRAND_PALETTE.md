# TagClaw 配色

共用颜色定义位于 `styles/brand.css`；普通内容页使用 `index.html` 中对应的 Tailwind 色阶，世界地图使用相同 CSS 变量。

| 用途 | 颜色 |
| --- | --- |
| 品牌橙：导航、主要操作、选中强调 | `#FF9F1C` |
| 深橙：浅底链接、强调文字 | `#B85B0D` |
| 浅橙：选中背景、标签 | `#FFF0D9` |
| 页面底色 | `#FBF8F3` |
| 卡片、浮层 | `#FFFDF9` |
| 正文 | `#302D27` |
| 次要文字 | `#786F64` |
| 分隔线 | `#E8DFD2` |

橙色用于建立品牌和操作层级；正文区域保持浅底深字。橙色导航沿用品牌的白色文字；背景铺满浏览器宽度，不受内容最大宽度限制。地图保留低饱和自然地形色，海域采用浅灰米色，小镇采用浅草色；不将所有地形染成橙色。绿色/青色、红色用于在线、涨跌和错误等真实状态。终端示例和专用数据画布可保持深色。

Logo 直接复用 `components/Icons.tsx` 导出的 `TagClawLogo`，与普通导航一致。
